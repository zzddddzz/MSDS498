# MSDS 498 Portfolio Action Console

Streamlit dashboard for the Northwestern MSDS 498 Team 54 capstone project.

## Deploy

Use Streamlit Community Cloud with:

- Repository: `zzddddzz/MSDS498`
- Branch: `main`
- Main file path: `streamlit_app.py`
- Secrets: none

## Local Run

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
streamlit run streamlit_app.py
```

The app uses public-safe segment-level demo data. The raw internal workbook is not included.
